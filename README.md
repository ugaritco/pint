<a name="introduction"></a>
## Introduction

**Ugarit Pint** is an opinionated PHP code style fixer for minimalists. Pint is built on top of **[PHP-CS-Fixer](https://github.com/FriendsOfPHP/PHP-CS-Fixer)** and makes it simple to ensure that your code style stays **clean** and **consistent**.

## Official Documentation

Documentation for Pint can be found on the [Ugarit website](https://ugarit.com/docs/pint).
